# 장기 온도 예측 구현

기존 pipeline.py 및 models/outputs는 수정하지 않습니다. 이 폴더의 코드는 프로젝트의 rawdata를 직접 읽습니다.

## 실행

프로젝트의 `long_term` 폴더에서 실행합니다. Python 3.9, numpy 2.0.2, pandas 2.2.3, torch 2.8.0(CPU), matplotlib 3.9.4, Pillow 환경에서 검증했습니다.

```powershell
python -m unittest test_forecast -v
python forecast.py --project .. --output runs/new_run
python forecast.py --project .. --output runs/initial --stage report
python forecast.py --project .. --output runs/initial --stage predict --experiment extended --as-of "2026-09-21 13:00"
```

`python`이 다른 환경을 가리키면 검증에 사용한 `C:\Python3.9\python.exe`로 실행합니다. 동일 run 폴더에 재학습하면 오류로 중지하여 기존 모델을 보존합니다. `--epochs`, `--patience`, `--seeds`, `--experiment core|extended|both`를 지정할 수 있습니다. 기본값은 최대 30 epoch, patience 7, seeds 17/29/43, 두 실험입니다. 특정 시각 예측은 학습된 모델에 맞는 모든 센서의 직전 24시간 관측이 있어야 합니다.

## 데이터 처리와 평가

- 원본의 빈 측정 행을 먼저 제외하여 정상 측정값을 덮어쓰지 않습니다. 일련번호/시각 중복은 2차 유효 관측을 우선합니다. 원본 해시를 기록하고 실행 종료에 재확인합니다.
- 장기 8개 센서: 학습 8/1~9/6, 검증 9/7~9/13, 시험 9/14~9/20.
- 확장 12개 센서: 학습 9/3~9/13, 검증 9/14~9/16, 시험 9/17~9/20. 남측11과 북측2/15/25 추가. 남측7은 철수되어 제외, 남측18은 좌표 미확정으로 제외.
- 원시 간격은 10분. 과거 144개 관측을 24개 시간 블록으로 요약합니다. 각 블록의 온도 평균/마지막 값, 습도 평균/마지막 값, 시각·요일 사인/코사인을 모든 모델에 동일하게 제공합니다. 시각/요일은 각 블록 마지막 시각 기준입니다.
- 목표는 기준 시각으로부터 1/3/6/12/24시간 후의 실제 10분 측정 온도입니다. 미래 시간평균이 아닙니다. 재귀적으로 자신의 출력을 입력하지 않고 다섯 목표를 직접 예측합니다.
- 학습·검증·시험 모두 기준 시각 간격 1시간. 입력 24시간과 마지막 목표 24시간이 모두 같은 분할에 있어야 합니다. 8개 실험 창 수는 841/121/121, 12개 실험은 217/25/49입니다. 작은 확장 시험의 안정성에 유의합니다.
- 스케일러는 각 실험의 학습 구간만으로 적합합니다. 결측값을 보간하지 않습니다. 불완전 관측이 있으면 중지합니다.
- GRU·LSTM은 모든 노드의 동일 입력을 받아 전체 노드 온도를 출력합니다. ST-GNN은 인과 시간 합성곱과 그래프 메시지 전달을 사용합니다. 각 구조의 파라미터 수는 별도 공개하며 파라미터 수가 동일한 비교는 아닙니다.
- 세 모델 모두 AdamW(lr=.001, weight_decay=.0001), batch 64, 정규화 온도 MSE, gradient clip 1을 사용합니다. 검증 원 단위 MAE로 조기종료/체크포인트를 선택합니다. 시험 데이터는 학습·선택에 사용하지 않습니다.
- 초기값별 평균·표준편차 및 개별 센서/요일/시간대 MAE·RMSE를 저장합니다. 초기값 편차는 날짜 변화에 대한 신뢰구간이 아닙니다. 전체 모델의 지도용 초기값은 검증 MAE로 선택하며 지도 시각은 시험 기준 시각의 중간 순번으로 고정합니다.
- 기존 탐색 분석에서 시험 기간을 이미 확인했기 때문에 완전한 블라인드 외부 평가로 간주하지 않습니다.

## 공간관계 및 도면

노드 좌표는 기존 도면의 원숫자를 사람이 읽은 정규화 좌표이며 실측 미터 단위가 아닙니다. 세 개의 가까운 이웃을 대칭 연결합니다. 자기 연결은 1입니다.

| 연결 | 정규화 전 사전 가중치 | 선 |
|---|---|---|
| N02 관련 | 0.01~0.02 | 옅고 가는 점선 |
| N15/N25 관련(N02 제외) | 0.15~0.25 | 중간 굵기의 실선 |
| 개방공간 | 0.50~1.00 | 진하고 굵은 실선 |

이는 사용자 조건을 수치화한 초기 가정이며 실측 열전달 계수가 아닙니다. 구간 안에서는 거리에 따라 감쇠합니다. 학습에서는 자기 연결을 포함해 행 정규화합니다. 두 형태 모두 CSV로 저장합니다. N02 자신의 과거 관측/자기 연결은 약화하지 않습니다. N15/N25의 열린 출입구 위치는 확인되지 않았으므로 실제 출입구를 통한 경로를 구현했다고 주장하지 않습니다.

빨간 엑스박스·빨간 네모는 바닥공조, 녹색은 천장형 FCU로 표기합니다. 풍량·급기온도·운전상태가 없어 설비를 임의 시계열 노드로 만들지 않습니다. 배경 그림은 원본 2차 PDF를 2400px PNG로 렌더링한 것입니다.

## Contour map의 의미와 한계

- 센서점은 학습 모델이 예측한 온도입니다. 공간 색상은 가우시안 RBF 보간/외삽입니다. 단일 센서로 관측한 N02/N15/N25 구획은 해당 예측값으로 균일하게 표시합니다.
- 도면 위 근사 구획을 분리하여 세 공간의 값을 개방공간 전체로 자동 확산하지 않습니다. 센서가 없는 구획은 마스킹합니다. 계단/창고 부분을 제외합니다. 구획 경계는 임시 사각형/폴리곤이며 실제 CAD 벽체 형상·출입구를 정확히 재현하지 않습니다.
- 센서 배치의 볼록껍질 밖은 외삽이므로 옅게 표시합니다. RBF는 센서값 범위 밖으로 벗어날 수 있으며 값을 몰래 잘라내지 않습니다. 색상 범위를 벗어난 값은 colorbar 끝 표시로 나타냅니다.
- 같은 실험의 모든 모델·시차에는 학습기간 온도 평균±2표준편차를 포괄하도록 0.5°C 단위로 확장한 공통 색상 범위를 사용합니다. 실제 방 전체의 실측 온도장 또는 CFD 결과가 아닙니다.
- `*_map_values.csv`에는 시험 예시의 센서 예측·실측이 함께 있습니다. `latest_forecast.csv`는 마지막 공통 관측(9/21 13:00) 이후의 예측이며 원칙적으로 정답 미확보로 표시합니다. 일부 단기 노드 관측이 뒤에 있더라도 전체 그래프의 사후 정답으로 처리하지 않습니다.

## 결과 파일

- `runs/initial/report.html`: 그래프와 contour map을 내장한 보고서
- `runs/initial/comparison.csv`: 두 실험의 모델·시차별 평균/표준편차
- 각 실험 폴더: 모델별 3개 checkpoint, epoch별 학습 기록, 세부 평가, 시험 예측 NPZ, 최신 예측 CSV, 그래프 가중치, 입력/목표 시간 경계
- `plots/STGNN_24h.png`: 고정 시험 예시의 +24시간 지도
- `plots/latest_STGNN_24h.png`: 마지막 공통 관측 이후 +24시간 지도
- `plots/graph.png`: 공간관계 가중치 지도
